# Session checklist

Copy this file to `songs/<song>/checklist.md` at the start of a song and tick each box there before moving on. After each element: render an 8-bar loop silently, compare it with the references (`skills/analysis.md`), fix it, save a numbered version and ask for a rating.

## Setup
- [ ] Read `taste_log.md` and `session_notes.md` (all "Rules learned" lines), `creative_direction.md` and `skills/best_practices.md`
- [ ] Read the newest trend report in `/mnt/project-files/scout/`; note 1 to 3 trend cues in the song sheet (none under 4 weeks old: say so and ask for a scout run)
- [ ] Pick the genre and 1 to 3 reference tracks; check each is in `references/` with a structure map
- [ ] Check `genre_guide.md` for tempo range and structure; choose tempo and key from the references
- [ ] Open `template.als`, Save As `<song>-v01.als` right away, then set tempo and key
- [ ] Mark the sections with locators (intro, build, drop, break, outro), using the same names as the reference structure map
- [ ] Check `sound_palette/` for approved sounds before browsing anything else

## Drums (`skills/drums.md`)
- [ ] Kick (four-on-the-floor)
- [ ] Clap or snare
- [ ] Closed hats and offbeat open hats
- [ ] Shakers and percussion for groove
- [ ] Groove and swing, velocity variation
- [ ] Naked groove test: kick, bass (once written) and one perc groove alone for a minute
- [ ] Drum bus check
- [ ] Loop rendered, compared, version saved, rating asked

## Bass (`skills/bass.md`)
- [ ] Bassline locked to the kick
- [ ] Sidechain or EQ so kick and bass don't clash
- [ ] Loop rendered, compared, version saved, rating asked

## Music
- [ ] One hook: short spoken or chopped vocal, or a synth stab (`skills/hook.md`); no vocals in a remake
- [ ] Hook alone test (hook + kick works without other parts)
- [ ] Loop rendered, compared, version saved, rating asked
- [ ] Chords or pads (`skills/atmosphere.md`)
- [ ] Atmosphere and textures
- [ ] Loop rendered, compared, version saved, rating asked

## FX and arrangement (`skills/arrangement.md`)
- [ ] Risers, impacts, sweeps: **one** transition device per transition, one impact (`skills/best_practices.md` section 5)
- [ ] Parts count per section written in the sheet and within budget (drop ≤ 8 parts, one hook, three focal parts)
- [ ] One change per 8-bar phrase; parts leave as often as they arrive
- [ ] Arrange the sections by the genre guide and the reference structure map
- [ ] Drums-only DJ intro and outro (16 to 32 bars)
- [ ] Automation so something changes every 8 or 16 bars
- [ ] Subtraction pass on each drop (mute each non-drum part; remove what the drop doesn't miss)
- [ ] FX check: no whole-mix effect in drops, automation back to start by the drop, no tails into the drop, each effect has a reason, new effects saved as their own version
- [ ] Section-by-section comparison with the reference (`sections.py`, `skills/analysis.md`); fix the biggest differences
- [ ] Version saved, rating asked

## Finish
- [ ] Mixdown checklist (`skills/mixdown.md`)
- [ ] Export the stems and premaster (`skills/export.md`)
- [ ] Ask Digi Arrow for a rating from 1 to 10 and a note; add it to `taste_log.md`
- [ ] Write `session_notes.md`
