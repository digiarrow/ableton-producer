# Samples log (clearance)

Every sample, loop, one-shot, vocal and preset-embedded sample used in each track, with its source and licence, so the track can be released safely. Fill it as you place each sound, not at the end. Rules in `skills/downloads.md` (Sample clearance).
Format per track: name · file or preset · pack and source URL · licence (royalty-free for commercial release? credit needed?) · where used (track, bars)

Stock Ableton sounds, our own synth patches (Vital, Surge XT, TAL, Drift) and presets with no embedded samples are cleared by default; list them only when they include a sample.
