# ableton-producer

Digi Arrow's music-production workspace for Ableton Live 12 (tech house / progressive techno), used with Claude and AbletonMCP.

## What's here
- `agents/` – skill files for the producer agent team (lead producer, sound design, music scout, reference analysis).
- `songs/` – one folder per song with a `sheet.md` (brief, key, tempo, form, track plan, decisions). Start new songs from `songs/_template/`.
- `tools/producer-agent/` – `record.py` and `analyze.py` for silent capture (BlackHole) and audio analysis against a reference.
- `screens/` – reference screenshots.
- `sheet.md` – working song sheet (Mariô remake).

Not included: the Live 12 manual PDF and reference book texts (large and copyrighted). They stay in the project's shared files.
